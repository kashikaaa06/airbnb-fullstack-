# 🌍 Travelxgo

**🔗 Live Demo:** [https://travelxgo.onrender.com](https://travelxgo.onrender.com)

## 📌 What is this?

A full-stack vacation rental platform where users can browse, list, and review properties.

## 🛠️ Built With

- 🟢 Node.js + Express.js
- 🍃 MongoDB + Mongoose
- 🔐 Passport.js (Authentication)
- 🎨 EJS + Bootstrap 5
- ☁️ Cloudinary (Image upload)
- 🚀 Render (Deployment)

## ✨ Key Features

- 👤 User login/signup
- 📝 Create, edit, delete listings
- 📸 Upload images
- ⭐ Leave ratings & reviews
- 🔍 Search & filter by category
- 📱 Mobile responsive
